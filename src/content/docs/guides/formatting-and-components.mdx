Starlight includes built-in support for rich technical documentation formatting.

## Callouts (Admonitions)

Use three colons (`:::`) to create styled notification boxes:

:::note
Standard informational callout for general context.
:::

:::tip[Best Practice]
Highlight shortcuts, tips, and recommended practices.
:::

:::caution
Alert readers to potential pitfalls or prerequisites.
:::

:::danger[Critical Warning]
Highlight actions that could cause data loss or system errors.
:::

***

## Interactive Tabs

Use `<Tabs>` when presenting operating-system-specific instructions or multi-language code:

<Tabs>
  <TabItem label="Windows">

    1. Press `Win + R`.
    2. Type `cmd` and press Enter.
  </TabItem>
  <TabItem label="macOS">
    3. Press `Cmd + Space` to open Spotlight.
    4. Type `Terminal` and press Enter.
  </TabItem>
</Tabs>

***

## Syntax-Highlighted Code Blocks

Add language tags, file titles, and line highlights to code snippets:

```javascript
title="config.js" mark={2}
// Highlighting specific lines helps draw attention
const API_URL = "[https://api.example.com/v1](https://api.example.com/v1)";
export default API_URL;
```
