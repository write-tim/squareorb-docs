Welcome to the official documentation hub. This knowledge base provides clear, structured, and accessible user documentation, built on a highly resilient modern architecture.

## System Architecture

This site operates on a strict **Docs-as-Code** philosophy, bringing the rigorous version control of software development to content strategy and technical writing. 

* **Frontend Framework:** Built with Astro Starlight, ensuring lightning-fast static page generation and a highly accessible, strictly typed reading experience.
* **Content Management:** Managed via Sveltia CMS, which provides a seamless graphical authoring interface while natively committing raw MDX files directly to the repository.
* **Automated Deployment:** GitHub Actions automatically validate frontmatter schemas and trigger rebuilds upon every batch publish, deploying live to the web in under 60 seconds.

## Navigating the Guides

The sidebar navigation is dynamically generated based on frontmatter metadata. Guides are categorized into logical workflows to help you quickly locate information:

* **Authoring and Publishing:** Step-by-step guides on creating content and utilizing the CMS workflow.
* **Formatting & Components:** References for using rich Markdown features, callouts, and custom UI components.

## Authoring Standards

To maintain consistency and readability across the knowledge base, we utilize standard Markdown enriched with custom MDX components. 

:::tip[Editorial Workflow]
To ensure system stability, all changes made via the CMS are routed through a Kanban-style Editorial Workflow. This allows contributors to safely draft, review, and batch-publish content without interrupting the live build environment. 
:::

Ready to dive in? Head over to the **Authoring and Publishing** guide to review the content creation process.
