Enhance user engagement with the following toggles:

- **Scroll Animations:** Animate images into view as the user scrolls down the page.

- **Category Filters:** Display filter buttons above the gallery if your images utilize categories.

- **Smart Search (Experimental AI):** Adds a live search bar allowing visitors to instantly filter gallery items.

- **Display Loading:** Control the "Initial Items to Show" (how many load immediately) and customize the "Load More" button's text, shape, and colors.
