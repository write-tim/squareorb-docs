Square Orb Gallery is built primarily for the Gutenberg block editor.

- **Adding Media:** If no images are selected, the block displays a prompt to assign media.

- **Reordering:** Use intuitive drag-and-drop functionality within the block settings sidebar to reorder how images appear in your gallery.

- **Video Integration:** Each image entry includes a "Video URL" field where you can paste YouTube, Vimeo, or standard MP4 links to play in the Lightbox.
