Installing the Square Orb Gallery plugin is straightforward, whether you install it via the WordPress dashboard or [download it from the official WordPress repository](https://wordpress.org/plugins/square-orb/).

Here is the step-by-step guide to getting the Square Orb Gallery plugin up and running.

### Method 1: Installing via the WordPress Dashboard (Easiest)

Use this method to install the plugin from the official WordPress.org plugin directory.

<Steps>

1. **Log in** to your WordPress admin dashboard.
2. Navigate to **Plugins** > **Add New** in the left-hand sidebar.
3. In the **Search plugins...** box (top right), search for the **Square Orb** plugin.
4. Once the plugin appears in the list, click the **Install Now** button.
5. After the installation completes, the button will change to **Activate**. Click it to enable the plugin.

</Steps>

### Method 2: Manual Upload

If you [download the `.zip` file from the WordPress repository](https://wordpress.org/plugins/square-orb/), follow these steps:

<Steps>

1. **Keep the file as a .zip:** Do not unzip the file before uploading.
2. **Log in** to your WordPress admin dashboard.
3. Navigate to **Plugins** > **Add New**.
4. At the top of the screen, click the **Upload Plugin** button.
5. Click **Choose File**, select the `square-orb.zip` file from your computer, and click **Install Now**.
6. Once uploaded, click **Activate Plugin**.

</Steps>

### Final Steps: Configuration

Most plugins require a bit of setup after activation:

- **Configure your settings in the Control Panel:** On the WordPress admin dashboard, click **Square Orb** to open the control panel. Use the **Global** tab for performance caching, asset protection, and optional telemetry, and use **Presentation Defaults** to set site-wide layout and lightbox styles.
- **Add your first gallery:** In any page or post editor, insert the **Square Orb Canvas** block from the block inserter.

**Troubleshooting Note:** If you encounter an unexpected error after activation, it is usually a conflict with another plugin. You can deactivate the plugin via FTP or file manager by renaming the plugin folder (e.g., changing `wp-content/plugins/square-orb` to `wp-content/plugins/square-orb-disabled`), which forces WordPress to deactivate it safely.
