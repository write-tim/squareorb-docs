<FAQ title="What cloud storage services does Square Orb Gallery support?">
Square Orb Gallery supports both Google Photos and Adobe Lightroom CC cloud import. Google Photos connects via OAuth and uses the Google Photos picker for selecting assets. Lightroom CC import is available when you configure Adobe credentials under the Authentication tab.
</FAQ>

<FAQ title="Can I use Square Orb Gallery without connecting a cloud account?">
Yes. Cloud import is optional. You can select images directly from your WordPress Media Library inside the Square Orb **Gallery Canvas** block and build galleries without any cloud connection.
</FAQ>

<FAQ title="How do I manage the layout of my galleries?">
Set site-wide defaults in **Global Defaults** for layout style, columns, spacing, and lightbox behavior. When the **Master Override Switch** is disabled, individual gallery blocks can override those defaults with block-level settings inside the Gutenberg sidebar.
</FAQ>

<FAQ title="How do I reset a gallery block to global defaults?">
Open the gallery block in the editor and click **Clear Canvas Overrides** in the block sidebar. This removes any local overrides and restores the current global settings for that gallery.
</FAQ>

<FAQ title="How does the “Master Override Switch” work?">
When enabled, the Master Override Switch forces every Square Orb Gallery block on the site to follow the centralized Global Defaults and disables per-block display overrides.
</FAQ>

<FAQ title="Can I protect my images from being downloaded?">
Yes. Square Orb Gallery includes **Right-Click Protection** for gallery items and lightbox images. This deters casual downloads, but it is a browser-side protection and not a substitute for secure asset delivery.
</FAQ>

<FAQ title="Does the gallery support image metadata?">
Yes. Square Orb Gallery can display **EXIF metadata** such as camera model, aperture, ISO, focal length, and shutter speed in the lightbox. You can toggle this globally or per block.
</FAQ>

<FAQ title="Is the plugin responsive?">
Yes. Square Orb Gallery is built responsively. Layouts like Grid, Masonry, Justified, Carousel, and Map adapt to different screen sizes, and you can configure separate **Mobile Columns** and **Desktop Columns**.
</FAQ>

<FAQ title="Can I add videos to my gallery?">
Yes. Each image entry can include a video URL (YouTube, Vimeo, or MP4) for playback inside the lightbox.
</FAQ>

<FAQ title="How do I update my gallery after adding new photos to a cloud album?">
Open the gallery block or Import Media tab, relaunch the cloud picker, and select the new images. Square Orb Gallery stores the selected media IDs, so re-running the picker and saving the block refreshes the gallery.
</FAQ>

<FAQ title="Do changes in Global Defaults affect existing galleries?">
Yes—unless a gallery block has local overrides enabled. Blocks without overrides inherit updated global defaults immediately, while blocks with overrides retain their custom settings until the overrides are cleared.
</FAQ>

## **Notes**

- Global defaults provide wide control, while block settings allow fine-tuned local overrides.
- Square Orb Gallery focuses on graceful image display with optional Lightbox overlays and asset protection.
- The plugin provides both Gutenberg block support and a shortcode fallback.
