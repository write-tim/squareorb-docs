If you need to place a gallery outside of the block editor (e.g., in a page builder or template file), Square Orb Gallery supports a shortcode fallback.

**Format:** `[square_orb ids="123,456,789" layout="grid" columns="4"]`

**Parameters:**

- `ids`: (Required) A comma-separated list of WordPress attachment IDs.

- `layout`: (Optional) Overrides the layout. Accepts `grid`, `masonry`, `justified`, `carousel`, or `map`.

- `columns`: (Optional) Overrides the desktop column count.
