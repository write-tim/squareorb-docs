To guarantee fast load times, Square Orb Gallery caches layout output and EXIF metadata extraction.

- **Performance Data Vault:** If you update image metadata or change underlying file details and the gallery does not reflect those changes immediately, click the **Purge High-Performance Cache** button in the Global Defaults tab to rebuild the output.
