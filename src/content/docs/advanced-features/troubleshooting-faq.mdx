| **Issue** | **Potential Solution** |
| --- | --- |
| **Gallery does not appear** | Ensure the block has selected image IDs. Check if the "Master Override Switch" is interfering with local block setups. If using a shortcode, verify the IDs are correct. |
| **Lightbox not working** | Verify that Lightbox settings are enabled in Global Defaults, and ensure the gallery container contains at least one valid image. |
| **Cloud import fails** | Re-authenticate your credentials on the Authentication tab. Ensure your API keys have the necessary permissions. |
