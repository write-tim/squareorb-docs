The Vision API enables the "Experimental AI Auto-Tagging" feature.

<Steps>

1. **Enable the Vision API:**
    - In your Google Cloud Project, navigate to **APIs & Services > Library**.
    
    - Search for **Cloud Vision API**.
    
    - Click on it and select **Enable**.

2. **Generate an API Key:**
    - Go to **APIs & Services > Credentials**.
    
    - Click **Create Credentials** and select **API key**.
    
    - A dialog will appear with your new API key. Copy this key.

3. **Restricting the Key (Recommended):**
    - For security, click **Edit API key** on your new key.
    
    - Under **API restrictions**, select **Restrict key** and choose **Cloud Vision API** from the dropdown.
    
    - Save your changes. Enter this key into the **Google Vision API Key** field in the **Square Orb > Authentication** tab, then click **Save Google Credentials**.

</Steps>

*Note: The AI Vision API auto-tagging feature is currently experimental and undergoing active troubleshooting.*
