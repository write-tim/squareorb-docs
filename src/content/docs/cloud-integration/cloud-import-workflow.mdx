Once authenticated, use the Import Media tab to sync files.

<Steps>

1. Go to **Aura Gallery > Import Media**.

2. Click **Select Cloud Photos via Google Canvas** (or the respective Adobe button).

3. Choose your assets in the cloud selector popup.

4. The plugin will sideload the selected media directly into your WordPress core.

</Steps>
