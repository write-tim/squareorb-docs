To enable the Adobe Lightroom CC integration, follow these steps via the Adobe Developer Console.

<Steps>

1. **Set up an Adobe Project:**
    - Navigate to the [Adobe Developer Console](https://www.google.com/search?q=https://developer.adobe.com/console/).
    
    - Click **Create new project**.

2. **Add an API:**
    - Click **Add to project** and select **API**.
    
    - Select **Lightroom API** (or the equivalent Creative Cloud API) and click **Next**.
    
    - Select **OAuth 2.0** as the authentication method.
    
    - Enter your **Redirect URI** (find this on the Aura Gallery plugin Authentication tab).
    
    - Save the configuration.

3. **Retrieve Credentials:**
    - Once the API is added, you will be presented with your **Client ID** (API Key) and **Client Secret**.
    
    - Copy these values immediately, as the secret may be hidden after you navigate away from the page.
    
    - Return to your WordPress dashboard and enter these credentials into the Adobe Lightroom CC section of the Aura Gallery Authentication tab.

</Steps>
